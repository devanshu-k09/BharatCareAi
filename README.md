# BharatCare AI

Intelligent Legal Assistance Platform. 
A comprehensive web application to help Indian citizens understand their legal rights, draft complaints, and locate government authorities.

## Project Structure
*   `frontend/` - Contains all HTML, CSS, and JS for the UI.
*   `backend/` - Node.js/Express server and MongoDB models.
*   `docs/` - Project documentation.

## Phase 1 Setup
- Express Server configured with routing and middleware.
- MongoDB connection using Mongoose.
- Environment variables configured.
- Docker configuration added (`Dockerfile` & `docker-compose.yml`).

## How to Run (Docker)
1. Run `docker-compose up --build -d`
2. API runs at `http://localhost:5000`
